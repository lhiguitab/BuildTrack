# Declaración de uso de IA - Lab 03

| Integrante o sistema | Modelo o herramienta | Uso en este laboratorio |
| --- | --- | --- |
| Codex (agente de IA) | GPT-5 | Análisis del RFP y de los slides, creación de prompts V1-V4, implementación de los slices, pruebas, documentación y operaciones Git. |
| Codex (herramientas) | PowerShell, Git, Python `unittest`, visor de imágenes | Inspección del repositorio, ejecución de pruebas, control de versiones y verificación visual de las indicaciones. |

No se infieren nombres, modelos ni herramientas de integrantes humanos que no hayan sido informados. Cada integrante que haya utilizado una herramienta adicional debe añadir su propia fila antes de entregar el laboratorio.
