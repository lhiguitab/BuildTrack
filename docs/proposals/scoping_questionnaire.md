# Scoping Questionnaire

**Question 1:**
What is the main problem you hope to solve with the system, and what impact does it currently have on project management?

**Question 2:**
Who are the users most affected, and what tasks do they perform?

**Question 3:**
What is the minimum information that must be recorded for each project, milestone, activity, field update, and incident?

**Question 4:**
Should the solution be integrated into the MVP with spreadsheets, email, file storage, or another existing tool?

**Question 5:**
Are there any technical, security, privacy, infrastructure, budget, or time-related constraints we need to consider?

**Question 6:**
How is a project's progress currently tracked, and what information must be included in every progress report or update?

**Question 7:**
What information should be included in the dashboard, and how would you like it to be displayed?

**Question 8:**
What situations would pose a significant risk to the adoption of the system for example, user resistance, incomplete information, delays in updates, or access issues?
