# Milestones Scope

Project phases for BuildTrack, based on the 16-week duration defined in the Statement of Work.

## Phase 1 — Requirements Analysis
- **Objective:** Gather and validate functional requirements with BuildRight.
- **Deliverable:** Requirements document.
- **Duration:** Week 1.
- **Dependencies:** Client availability for interviews.

## Phase 2 — System Design
- **Objective:** Define architecture, data model, and interface design.
- **Deliverable:** Interface and database design.
- **Duration:** Week 2.
- **Dependencies:** Requirements document approved (Phase 1).

## Phase 3 — Development: Projects and Milestones
- **Objective:** Build project and milestone management modules, including assigned person, target date, and the authorized-role control for editing it.
- **Deliverable:** Development progress report.
- **Duration:** Weeks 3–6.
- **Dependencies:** Design approved (Phase 2).

## Phase 4 — Development: Tasks and Issues
- **Objective:** Build task status updates and issue logging, including the mandatory issue + responsible-person flow when a milestone is blocked.
- **Deliverable:** Development progress report.
- **Duration:** Weeks 7–10.
- **Dependencies:** Projects module functional (Phase 3).

## Phase 5 — Development: Dashboard and Weekly Summary
- **Objective:** Build the dashboard (at-risk / delayed / blocked) and the read-only weekly summary for clients.
- **Deliverable:** Development progress report.
- **Duration:** Weeks 11–14.
- **Dependencies:** Task and issue data available (Phase 4).

## Phase 6 — Testing and Bug Fixing
- **Objective:** Functional and integration testing, bug fixing.
- **Deliverable:** Test report.
- **Duration:** Week 15.
- **Dependencies:** All modules developed (Phases 3–5).

## Phase 7 — Final Delivery
- **Objective:** Deployment, basic training, and client presentation.
- **Deliverable:** Implementation and presentation.
- **Duration:** Week 16.
- **Dependencies:** Test report approved (Phase 6).
