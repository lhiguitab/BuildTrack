# MVP Scope

## Scope Items

## IN

- Web application compatible with computers, tablets, and cell phones.
- Create and view projects.
- Create milestones associated with each project.
- Record the person responsible, target date, and status of each milestone.
- Field supervisors update progress.
- Record issues or obstacles associated with milestones.
- Mandatory recording of the issue and the person responsible when a milestone is blocked.
- Display of at-risk, delayed, and blocked milestones.
- Dashboard to facilitate project tracking.
- Generation of a weekly summary for clients every Friday.
- Clients without editing permissions.
- Control ensuring that only an authorized role can modify the target date.

---

## OUT

- Comprehensive budget and cost management.
- Purchasing and procurement processes.
- Supplier and inventory management.
- BIM capabilities.
- Advanced geolocation.
- Native mobile app.
- Offline data entry.
- Editing permissions for clients.
- Comprehensive financial and accounting control system.
- Features typical of comprehensive construction business software.

---

## LATER

- Native mobile app for field supervisors.
- Offline logging and synchronization of updates.
- Automatic notifications about overdue or upcoming milestones.
- Project portal for clients to view project status.
- Advanced uploading and organization of construction site photos.
- Integrations with spreadsheets, email, and cloud storage.
- History and audit trail of changes to committed dates.
- Advanced metrics and progress trend analysis.
- Geolocation features.
- Cost, procurement, and BIM modules, subject to future evaluation.

---

## UNKNOWN

- Which role can change a milestone’s target date?
- How is it determined that a milestone is “at risk”?
- What information and format should the weekly summary include?
- Should the report be viewed on screen, downloaded as a PDF, or sent by email?
- Will clients log in to the system in view-only mode, or will they only receive the summary?
- Should field updates allow users to attach photos or documents?
- How often should supervisors record progress?
- Is it required to maintain a history of changes?
- What specific permissions will each user type have?
