# BuildTrack: showcase de skills

Borrador de una presentación de 5 minutos. Incluye diez skills investigadas, sus veredictos provisionales, hallazgos y el protocolo de una demo en Codex. La demo y la skill propia siguen pendientes de ensayo e implementación.

- [Ver el PDF](BuildTrack-Skills-Showcase.pdf)
- [Descargar el PowerPoint editable](BuildTrack-Skills-Showcase.pptx)

## Tiempo propuesto

| Parte | Duración |
|---|---|
| Contexto de BuildTrack | 30 s |
| Diez skills con sus veredictos | 100 s |
| Hallazgos y descartes | 40 s |
| Skill propia propuesta | 20 s |
| Demo en Codex | 95 s |
| Cierre | 15 s |

Total planificado: 5 minutos. Requiere ensayo con cronómetro. El PowerPoint contiene notas para exponer y referencias. No se han medido mejoras ni ejecutado la comparación como parte de este borrador.
