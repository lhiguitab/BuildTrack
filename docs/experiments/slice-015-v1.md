# Experimento de prompts - Slice 015 - V1

## Propósito

Evaluar cuánto puede implementar un agente con un prompt mínimo, sin contexto adicional del repositorio ni criterios explícitos.

## Slice

Un hito no puede marcarse como completado si tiene tareas abiertas.

## Prompt único

```text
Implementa la regla: un hito no puede marcarse como completado si tiene tareas abiertas.
```

## Restricción del experimento

Aplicar únicamente el prompt anterior en esta rama. No complementar el pedido con información adicional durante la implementación.

## Evaluación posterior

Calificar el resultado sobre 8 criterios comunes con las ramas V2, V3 y V4. Registrar el puntaje y las observaciones al finalizar la ejecución.
